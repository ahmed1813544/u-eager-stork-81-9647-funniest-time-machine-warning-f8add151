Entry for the [Funniest Time Machine Warning Label](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151) bounty on make.fun.

## The label

> WARNING: If you meet yourself, do not lend him money. He never pays it back.

## How it works

`main.py` (stdlib only, no third-party imports) writes that single warning
label — 76 characters, no trailing newline — to `/output/entry.txt`.
The output is deterministic: every run produces byte-identical output.

Run it with:

```sh
python3 main.py
```
